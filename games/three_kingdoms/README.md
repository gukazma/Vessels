# 三国 · 战术试验场

这是独立于旧项目的《英雄连》式三国小队战术原型。打开本目录的 `project.godot`，使用 Godot 4.6.1 运行。当前先验证玩法，使用灰盒战场与占位角色。

## 当前阶段：M2-01 掩体与面向

默认入口为 `levels/cover_encounter.tscn`：双方各一队盾步兵和一队弓兵，每队 7 人。敌军守住阵地；玩家比较正面交战与牵制绕侧，决定是否用绕路时间和前排损失换取更好的攻击方向。全部敌军被消灭即胜利，我军全部被消灭即失败，双方同时被消灭则平局。结束显示伤亡，可随时重开。

M2-01 当前已实现并通过检查、待试玩；具体防护规则、三个对照练习与验收见 [有方向的掩体与面向](../../docs/three-kingdoms/directional-cover-rules.md)。M1 已实现并通过检查，用户允许继续，平衡仍可调整；F1 保留 [基础遭遇战](../../docs/three-kingdoms/first-battle-rules.md) 作为对照。完整路线见 [从 0 到 1 开发方案](../../docs/three-kingdoms/development-plan.md)。

| 操作 | 输入 |
| --- | --- |
| 选择友方存活小队 | 左键点击 |
| 框选 | 按住左键拖拽 |
| 加选 / 取消单队 | Shift + 点击或框选 |
| 快捷选队 / 全选 | 1 盾步兵，2 弓兵；Tab 全选 |
| 移动 / 指定攻击 | 右键空地 / 敌军；替换旧命令 |
| 追加移动或攻击 | Shift + 右键，每队最多 16 条命令（含当前命令） |
| 清空命令并原地守卫 | X |
| 朝鼠标定向守卫（M2） | Q；清空命令、保持阵地和指定方向，不为侧后敌人自动转头 |
| 战术暂停 / 恢复 | Space；暂停中仍可选队和下令 |
| 聚焦选中部队 | F |
| 清除选择 | Esc |
| 重开遭遇战 | R |
| 切换练习 | F1 基础遭遇战；F2 掩体与面向 |
| 镜头平移 | WASD 或鼠标中键拖拽 |
| 镜头缩放 | 鼠标滚轮 |

移动命令不会自动停下攻击；指定攻击会接近目标；原地守卫只打合法射程和视线内的目标，不主动追远。M2 每秒最多转身 180°，朝向与目标相差不超过 30° 才能攻击；X 可自动转向目标，Q 锁定指定方向。移动或攻击命令解除方向锁定。暂停时可发 Q 和其他命令，但旋转、移动、伤害和冷却均不推进。

M2 盾牌正前 120° 承受 65% 远程伤害，侧背承受 100%；矮掩体保护带深 72，位于带内且从正面隔墙射来的箭伤害为 50%，绕端、背袭或离带不会获得这项保护。盾牌与掩体取更强的一项，不相乘；近战不享受上述远程减伤。矮墙挡路不挡箭，高墙挡路也挡箭，两种墙都阻挡隔墙近战。朝向、防护弧、保护区和悬停敌军的伤害预览用于判断攻防位置；预览同时说明超出射程、转向中或遮挡等限制。

本轮只新增 M2-01，不含士气、主动撤退、补给、招募、资源与攻城。领队仍是最后阵亡的普通成员，不是独立武将系统；弓兵贴身受压仍有效。双方兵力相等，尚未完成以弱胜强验证。

## M1 基础遭遇战

F1 进入 `levels/encounter.tscn`，保留 M1 的全向盾牌远程减伤、敌军警戒追击及高墙阻挡，用于练习基础交战或与新规则对照；F2 返回掩体练习。M1 的旧规则文档作为该模式基线保留。

## M0 指挥训练场

`levels/command_sandbox.tscn` 保留三支友方小队，用于练习选择、队形、移动、绕障碍与镜头。可在 Godot 编辑器中打开该场景，按 F6 单独运行。训练场没有敌军或伤害。

## 检查

在仓库根目录执行统一检查：

```powershell
./tools/check.ps1 -Godot 'C:\Program Files\Godot\Godot.exe'
```

只检查独立三国项目：

```powershell
./games/three_kingdoms/tools/check.ps1 -Godot 'C:\Program Files\Godot\Godot.exe'
```

统一检查已通过：导航 32 项，指挥、交战、实际输入和方向防护在 60 / 120 Hz 各 190 项，共 412 项检查；另有导入和入口启动检查。包含防护方向与叠加、转向后攻击、Q 定向守卫、暂停冻结、M1 规则回归及 F1/F2 切换。检查通过后仍需用户试玩，重点比较保护方向是否易懂、转向节奏是否合适，以及绕路时间和牵制损失能否换来值得的攻击角度。

预览脚本使用实际渲染器核对部署、交战、暂停和结算画面。下面运行 M2 正攻方案；追加 `--flank` 运行牵制绕上端方案；去掉 `-- --cover` 则运行 M1：

```powershell
& 'C:\Program Files\Godot\Godot.exe' --path ./games/three_kingdoms --fixed-fps 60 --script res://tools/capture_encounter_preview.gd -- --cover
```

截图生成在新项目的 `.godot/` 内，不提交缓存。小队当前允许互相穿行，尚未实现实体阻挡；屏幕上的兵种、人数、血条与受压提示用于检查规则可读性。
