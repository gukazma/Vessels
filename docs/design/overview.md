# Vessels - 游戏总览

## 基本信息

| 属性 | 值 |
|------|-----|
| 游戏名称 | Vessels (器皿) |
| 类型 | 生存/养成/策略 RPG |
| 视角 | 2D 俯视角像素风 |
| 平台 | PC (Godot 4.x) |
| 单局时长 | 2-4 小时 |

## 核心概念

**"在末日来临前，你只是一个普通人"**

玩家扮演一个普通的现代都市人，过着平凡的日常生活。然而，第七天，僵尸末日突然爆发。你在和平时期建立的人脉、积累的资源、学习的技能，将决定你能否在末日中生存下去。

## 三大核心融合

### 1. 星露谷式养成 (Day 1-6)
- 日常工作赚钱
- 与 NPC 建立关系
- 购物、升级装备
- 时间管理

### 2. 僵尸毁灭工程式生存 (Day 7+)
- 资源搜刮
- 据点建设与防御
- 僵尸战斗
- 生存压力管理

### 3. 三国志式人才招募
- NPC 有独特属性和技能
- 通过好感度/任务招募
- 人才决定据点发展方向
- 团队协作生存

## 核心循环

```
┌─────────────────────────────────────────────────────┐
│                    和平阶段 (Day 1-6)                │
│  起床 → 上班 → 下班 → 自由活动 → 睡觉              │
│         ↓                ↓                          │
│      赚取金钱         结交NPC/购物/探索             │
└─────────────────────────────────────────────────────┘
                         ↓ Day 7 末日爆发
┌─────────────────────────────────────────────────────┐
│                    生存阶段 (Day 7+)                 │
│  醒来 → 分配任务 → 搜刮/建设/战斗 → 夜间防御       │
│              ↓              ↓                       │
│         管理人才        消耗资源                    │
└─────────────────────────────────────────────────────┘
```

## 目标玩家

- **主要受众**: 喜欢生存游戏和养成游戏的玩家
- **年龄段**: 18-35 岁
- **游戏习惯**:
  - 玩过星露谷物语、动物森友会
  - 玩过 Project Zomboid、7 Days to Die
  - 喜欢像素风独立游戏
- **期望体验**:
  - 在轻松养成中隐藏的末日紧张感
  - 人际关系影响生存的策略深度
  - "如果末日来临，你准备好了吗？" 的代入感

## MVP 范围定义

### 核心功能 (必须实现)

| 功能 | 描述 | 预估工时 |
|------|------|----------|
| 玩家移动 | WASD 八方向移动 | 1h |
| 时间系统 | 日夜循环，7天周期 | 2h |
| 工作系统 | 简化版上班赚钱 | 1h |
| 商店系统 | 购买物品 | 1h |
| 物品栏 | 背包管理 | 2h |
| NPC系统 | 3个可招募NPC | 2h |
| 对话系统 | 简单对话/好感度 | 1h |
| 战斗系统 | 近战攻击僵尸 | 2h |
| 僵尸AI | 基础追踪/攻击 | 2h |
| 据点系统 | 简化版建造 | 2h |

**总计: 约 16 小时 (可在两个晚上完成)**

### 简化内容 (MVP版本)

- 地图: 1 个小型城镇 (32x32 tiles)
- 建筑: 家、公司、商店、医院、空地
- NPC: 3 个可招募角色
- 物品: 15 个核心物品
- 僵尸: 1 种普通僵尸

### 延后功能 (后续迭代)

- 多种僵尸类型
- 更多 NPC 和剧情
- 复杂的建造系统
- 存档系统
- 音效和音乐

## 成功指标

1. **玩家能完成 7 天循环**: 从和平到末日的完整体验
2. **人际关系有意义**: 招募的 NPC 确实影响生存
3. **末日转折有冲击**: Day 7 的爆发让玩家措手不及
4. **重玩价值**: 不同职业/选择带来不同体验

## 技术栈

- **引擎**: Godot 4.x
- **美术**: Aseprite (16x16 像素风格)
- **分辨率**: 320x180 (放大到 1280x720)
- **帧率**: 60 FPS
- **存储**: JSON 格式存档
