# Vessels - 据点系统

## 概述

据点是生存阶段的核心。玩家需要建设和维护据点，抵御僵尸攻击，为队员提供生活空间。

## 据点属性

### 核心属性

| 属性 | 初始值 | 最大值 | 说明 |
|------|--------|--------|------|
| 防御值 | 50 | 200+ | 抵御僵尸攻击的能力 |
| 食物存储 | 0/50 | 可扩展 | 存储的食物数量 |
| 舒适度 | 30 | 100 | 影响队员士气和恢复 |
| 人口上限 | 2 | 10+ | 最多容纳的队员数量 |

### 据点等级

| 等级 | 要求 | 解锁 |
|------|------|------|
| 1 | 初始 | 基础建筑 |
| 2 | 防御值 100+, 舒适度 50+ | 中级建筑 |
| 3 | 防御值 150+, 舒适度 70+, 5人+ | 高级建筑 |
| 4 | 防御值 200+, 舒适度 90+, 8人+ | 特殊建筑 |

## 每日消耗

### 食物消耗

| 人口 | 每日消耗 | 说明 |
|------|----------|------|
| 1 人 | 10 食物 | 基础消耗 |
| 2-3 人 | 9 食物/人 | 规模效益 |
| 4-6 人 | 8 食物/人 | 进一步优化 |
| 7+ 人 | 7 食物/人 | 最大效率 |

**食物不足影响**:
- 食物储量 0: 全员饥饿 -30/天，士气 -20
- 连续 3 天无食物: 全员生命 -10/天
- 连续 7 天无食物: 随机队员死亡

### 防御损耗

| 条件 | 每夜损耗 |
|------|----------|
| 无僵尸攻击 | -0 |
| 少量僵尸 (1-5) | -5 |
| 中量僵尸 (6-15) | -15 |
| 大量僵尸 (16-30) | -30 |
| 僵尸潮 (30+) | -50 |

**防御值归零时**:
- 僵尸突破防线
- 随机队员受伤 (30 伤害)
- 据点物资被破坏 (损失 20% 存储)

### 舒适度影响

| 舒适度 | 效果 |
|--------|------|
| 0-20 | 士气 -10/天，恢复速度 -50% |
| 21-40 | 士气 -5/天 |
| 41-60 | 无额外效果 |
| 61-80 | 士气 +5/天，恢复速度 +20% |
| 81-100 | 士气 +10/天，恢复速度 +50% |

## 建造流程

### 1. 选择建筑
```
打开建造菜单 → 选择类别 → 选择建筑 → 查看所需材料
```

### 2. 分配建造任务
```
选择建造者 → 建造速度 = 基础时间 / (1 + 建造属性 * 0.1)
```

### 3. 等待完成
```
建造进度实时显示 → 完成后自动生效
```

### 建造效率计算

| 建造属性 | 效率加成 | 示例 (4小时基础) |
|----------|----------|------------------|
| 0 | 100% | 4 小时 |
| 3 | 130% | 3.1 小时 |
| 5 | 150% | 2.7 小时 |
| 8 | 180% | 2.2 小时 |
| 10 | 200% | 2 小时 |
