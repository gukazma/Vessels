# Vessels - 数值平衡

## 概述

本文档定义游戏的核心数值系统，包括玩家属性、时间系统、经济系统和战斗系统。所有数值都经过计算以确保游戏体验的平衡性。

### 夜间防御战

#### 僵尸攻击强度
| 天数 | 僵尸数量 | 总生命 | 据点伤害/夜 |
|------|----------|--------|-------------|
| Day 8-10 | 5-10 | 250-500 | 10-20 |
| Day 11-15 | 10-20 | 500-1000 | 20-40 |
| Day 16-20 | 20-30 | 1000-1500 | 40-60 |
| Day 21+ | 30+ | 1500+ | 60+ |

#### 防御计算
```
夜间据点伤害 = 僵尸总攻击 - 据点防御值 * 0.5 - 守卫总输出
```

**示例**: Day 10，10只僵尸攻击
- 僵尸总攻击: 10 * 15 = 150
- 据点防御 50: 150 - 25 = 125 伤害
- 2名守卫 (DPS 15 + 20): 125 - (15+20)*5轮 = 125 - 175 = 0 (安全)

## 平衡公式汇总

### 战斗公式
```
实际伤害 = 武器伤害 + 战斗属性 * 2
DPS = 实际伤害 * 攻击速度
命中率 = 90% + 战斗属性 * 2%
```

### 建造公式
```
实际建造时间 = 基础时间 / (1 + 建造属性 * 0.1)
材料节省 = 建造属性 * 2%
```

### 医疗公式
```
实际治疗量 = 基础治疗 * (1 + 医疗属性 * 0.1)
```

### 搜刮公式
```
搜刮效率 = 基础效率 * (1 + (社交属性 + 探索加成) * 0.05)
```

### 好感度公式
```
好感度获取 = 基础获取 * (1 + 社交属性 * 0.1)
```
