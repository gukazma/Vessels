# Vessels - 职业系统

## 概述

玩家在游戏开始时选择职业，职业决定:
- 起始属性加成
- 起始物品
- 工作地点和日薪
- 特殊技能

## 基础属性说明

| 属性 | 描述 | 影响 |
|------|------|------|
| 战斗 | 战斗能力 | 武器伤害+X%, 攻击速度 |
| 建造 | 建筑能力 | 建造速度+X%, 资源消耗-X% |
| 医疗 | 医疗能力 | 治疗效果+X%, 药品效率 |
| 社交 | 社交能力 | 好感度获取+X%, 招募成功率 |
| 烹饪 | 烹饪能力 | 食物效果+X%, 食材利用率 |

**基础值**: 所有属性默认为 0，职业提供加成

## 职业一: 办公室职员 (Office Worker)

### 背景故事
> "每天朝九晚五，在格子间里对着电脑发呆。你以为这辈子就这样了，直到世界末日来临..."

### 属性加成

| 属性 | 加成 | 说明 |
|------|------|------|
| 战斗 | +0 | 没有战斗经验 |
| 建造 | +0 | 只会修电脑 |
| 医疗 | +0 | 只会贴创可贴 |
| 社交 | +5 | 职场生存必备技能 |
| 烹饪 | +2 | 经常点外卖，偶尔做饭 |

### 起始物品

| 物品 | 数量 | 说明 |
|------|------|------|
| 公文包 | 1 | 额外 4 格物品栏 |
| 能量饮料 | 3 | 恢复 20 体力 |
| 智能手机 | 1 | 可查看新闻/地图 |
| 现金 | 200 | 起始资金 |

### 工作信息

| 属性 | 值 |
|------|-----|
| 工作地点 | 办公大楼 |
| 工作时间 | 09:00 - 18:00 |
| 日薪 | 80 金币 |
| 工作消耗 | 30 体力 |

### 特殊技能

**【人脉广阔】**
- 类型: 被动技能
- 效果: NPC 初始好感度 +10
- 说明: 职场多年积累的社交经验

**【PPT之力】**
- 类型: 主动技能
- 冷却: 1 天
- 效果: 与 NPC 交流时，额外获得 50% 好感度
- 说明: 用演示文稿说服别人的能力

## 职业二: 建筑工人 (Construction Worker)

### 背景故事
> "搬砖搬了十年，手上的老茧比脸皮还厚。没想到这些技能在末日里派上了大用场..."

### 属性加成

| 属性 | 加成 | 说明 |
|------|------|------|
| 战斗 | +3 | 有力气就能打 |
| 建造 | +5 | 专业技能 |
| 医疗 | +0 | 小伤不用管 |
| 社交 | +0 | 话不多说 |
| 烹饪 | +1 | 工地饭菜将就吃 |

### 起始物品

| 物品 | 数量 | 说明 |
|------|------|------|
| 安全帽 | 1 | 头部防御 +5 |
| 工具箱 | 1 | 建造速度 +20% |
| 盒饭 | 2 | 恢复 30 饥饿 |
| 现金 | 120 | 起始资金 |

### 工作信息

| 属性 | 值 |
|------|-----|
| 工作地点 | 建筑工地 |
| 工作时间 | 07:00 - 17:00 |
| 日薪 | 100 金币 |
| 工作消耗 | 50 体力 |

### 特殊技能

**【铁人】**
- 类型: 被动技能
- 效果: 最大生命值 +20，体力消耗 -20%
- 说明: 多年重体力劳动锻炼的身体

**【紧急加固】**
- 类型: 主动技能
- 冷却: 1 天
- 消耗: 20 体力
- 效果: 立即修复据点 30% 防御值
- 说明: 快速修补建筑的本能

## 职业三: 医生 (Doctor)

### 背景故事
> "在医院见惯了生死，你以为自己已经麻木了。但当病人开始咬人的时候，你知道一切都变了..."

### 属性加成

| 属性 | 加成 | 说明 |
|------|------|------|
| 战斗 | +0 | 救人不杀人 |
| 建造 | +0 | 不是这个专业 |
| 医疗 | +10 | 专业技能 |
| 社交 | +3 | 医患沟通经验 |
| 烹饪 | +0 | 只吃食堂 |

### 起始物品

| 物品 | 数量 | 说明 |
|------|------|------|
| 医疗包 | 1 | 可使用 5 次，每次恢复 40 生命 |
| 手术刀 | 1 | 近战武器，伤害 15 |
| 抗生素 | 2 | 治疗感染状态 |
| 现金 | 300 | 起始资金 (医生收入高) |

### 工作信息

| 属性 | 值 |
|------|-----|
| 工作地点 | 医院 |
| 工作时间 | 08:00 - 20:00 (长班) |
| 日薪 | 150 金币 |
| 工作消耗 | 40 体力 |

### 特殊技能

**【专业诊断】**
- 类型: 被动技能
- 效果: 医疗物品效果 +50%，可识别 NPC 健康状态
- 说明: 医学院七年没白读

**【急救处理】**
- 类型: 主动技能
- 冷却: 无 (消耗医疗物品)
- 效果: 对自己或队友进行急救，恢复 50% 最大生命值
- 说明: 在最危急的时刻稳定伤员

## 职业推荐

### 新手推荐: 办公室职员
- 社交加成让招募 NPC 更容易
- 起始资金适中
- 工作时间规律，有充足自由时间

### 进阶推荐: 建筑工人
- 战斗和建造加成在末日后非常有用
- 高体力消耗需要合理规划
- 适合喜欢建设和战斗的玩家

### 挑战推荐: 医生
- 医疗专精，但其他属性弱
- 高收入但工作时间长
- 需要依赖招募的 NPC 来补足短板
