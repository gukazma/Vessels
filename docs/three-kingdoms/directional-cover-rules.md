# M2-01：有方向的掩体与面向

本轮只推进 M2-01，状态为**已实现并通过检查，待用户试玩**。目标是让玩家看懂保护来自哪个方向，再决定是否付出绕路时间和牵制伤亡去换一个更好的攻击位置。仍用灰盒地图，不制作正式美术。

M1 基础遭遇战保留为对照，规则见 [第一场遭遇战玩法规格](first-battle-rules.md)。用户已允许继续开发，不表示 M1 的平衡已经验收。M2-01 尚未加入士气、主动撤退、补给、骑兵或弱势兵力验证关，不能把本轮交付等同于“以弱胜强已经完成”。

## 1. 两个练习入口

| 入口 | 用途与规则 |
| --- | --- |
| 默认 / F2：`levels/cover_encounter.tscn` | M2 掩体练习：有方向的盾牌、矮掩体、有限转向和定向守卫；敌军守住驻位，可转头攻击但不追离阵地 |
| F1：`levels/encounter.tscn` | M1 基础遭遇：保留原全向盾兵远程减伤与警戒追击，便于重玩基础指挥和交战 |

新练习仍是双方各一队盾步兵和一队弓兵，每队 7 人。人数、基础生命、伤害、攻击间隔与 M1 一致；伤亡继续降低输出，胜负与战报规则也保持一致。R 重开当前练习。

敌方固守是本轮用于比较攻击方向的关卡规则，不是新增了一套完整防御战 AI。敌军可以转向，因此走到侧面并不保证一直获得侧击机会：另一队能否维持威胁、何时抵达、绕路时损失多少，都是要比较的取舍。

## 2. 防护根据来袭方向判断

| 防护 | 生效条件 | 远程伤害倍率 | 不生效的情况 |
| --- | --- | --- | --- |
| 盾牌 | 来袭者位于盾兵当前朝向的正前方 120° 范围内，即左右各 60° | 65% | 从盾兵侧面或背面来袭；转向尚未把攻击者纳入防护弧 |
| 矮掩体 | 受击小队位于掩体指定保护侧、深度 72 的保护带内，来袭射线从正面穿过相应矮墙 | 50% | 绕过墙端从侧面来袭、从保护带背后来袭，或受击队离开保护带 |
| 高墙 | 高墙处在攻击射线上 | 不能命中 | 没有射线遮挡时按其他防护规则结算 |

保护带和射线按小队中心判断，暂不逐名士兵判断身体是否探出墙角。矮掩体方向由阵地本身决定；盾牌方向随小队当前朝向变化，二者不能混为一谈。只有进入保护带还不够，来袭方向也必须让矮墙实际挡在射手和目标之间。

矮墙挡路，但允许箭矢越过；高墙既挡路又挡箭。矮墙和高墙都会从两个方向阻挡隔墙近战。近战不享受盾牌或掩体的上述远程减伤，但仍须先绕到能合法接敌的位置。

同一攻击同时满足盾牌与掩体时，**只取更强的一项保护，不连乘**。例如 7 人弓队一次基础伤害为 28：

| 当前受击条件 | 预计伤害（未受贴身压制） |
| --- | --- |
| 无防护，或只打到盾兵侧背 | 28 |
| 只有正面盾牌 | 18.2 |
| 只有有效掩体 | 14 |
| 有效掩体与正面盾牌同时成立 | 14 |

侧背不提供额外暴击或伤害加成，只是不再享受正面盾牌减伤；若该方向仍满足掩体保护，掩体依然有效。弓兵在 70 距离内存在能直接接敌的敌军时，输出降至 35%，再结算目标的有效防护。M2 中矮墙隔开的近敌不会触发贴身压制，因为近战不能越墙；M1 原有压制规则不变。

## 3. 转头需要时间，守哪个方向由玩家决定

M2 小队每秒最多转向 180°。实际攻击必须等目标进入当前朝向左右各 30° 的攻击范围；伤害不能先于转身发生。盾牌保护弧为左右各 60°，攻击范围为左右各 30°，两者宽度不同。

| 指令 | 行为与取舍 |
| --- | --- |
| Q：朝鼠标定向守卫 | 清空当前与排队命令，原地转向鼠标所指方向并锁定。只攻击该固定方向左右各 30° 的合法目标，不为侧后的敌人自动转头 |
| X：普通守卫 | 清空命令、原地守卫，可自动转向射程内的合法目标；能回应侧面威胁，也可能将盾背暴露给另一侧 |
| 右键移动 / 攻击 | 取消定向锁定，执行移动或指定攻击；攻击仍需满足实际朝向、射程和遮挡条件 |
| Space：暂停下令 | 暂停中可以发 Q、移动和攻击命令；实际旋转、移动、伤害与冷却全部冻结，恢复后才执行 |

定向守卫不是固定朝向就能攻击任意敌人的增益。它帮助盾兵守住预判的箭雨方向，却可能错过旁边的攻击机会；普通守卫更灵活，却需要留意转身造成的短暂暴露。玩家可沿用 Shift + 右键队列规划绕墙移动与攻击，但 Q 会清空该队旧计划。

## 4. 操作前应该能读懂什么

界面需要显示小队朝向、盾牌防护弧和矮掩体保护区。选队后悬停敌军，应能看到预计单轮伤害，以及当前受益于“掩体”“正面盾”还是处于“侧背”等读数，用于解释同一弓队换位置后伤害为何变化。

预览根据当前兵力、位置、目标朝向和受压状态计算，并显示“超出射程”“转向中”“遮挡”等当前限制。它是当前这一击的估算，不是整场胜负预测；条件尚未满足时，不能把一个伤害数字理解成立即可以命中。转身、减员或换位都会改变后续读数。

本轮反馈优先服务决策：看得出哪面受保护、绕到哪里会失去保护、是否还在转头。不会以增加装饰细节代替规则可读性。

## 5. 三个可重复练习

1. **看懂保护的来源**：F2 进入后，用弓队从敌方阵地正面接近，暂停并悬停目标，记录防护来源、人数和伤害预览。重开后沿矮墙端部绕到侧面，再暂停查看同一目标。优先比较防护倍率与提示；只有攻击方人数和受压状态相同时才直接比较伤害数值。盾兵若已转向你，要区分仍存在的盾牌保护与已经失效的掩体保护。
2. **比较定向与自动转头**：把我方盾队移至敌弓队能攻击、没有掩体保护的位置，暂停、将鼠标指向射手并按 Q。确认暂停时朝向没有提前改变；恢复后观察转向过程和防护弧。再次暂停，Q 指向另一侧并恢复，比较侧背受击；重开后用 X 普通守卫对照。记录锁定方向是否符合预期，而不是把每次受伤不同都归因于随机数。
3. **比较正攻与牵制绕侧**：先让两队正面交战，记录结算人数。重开后让一队在正面维持威胁，另一队用 Shift + 右键排出绕墙端部、接近和攻击的路线；暂停帮助同步接战。记录绕路耗时、牵制队的伤亡、绕侧后防护读数与最终幸存人数。若绕路损失超过收益，先调整时机再比较，不预设该打法必胜。

练习 1 验证“我为什么打不疼”，练习 2 验证“我是否愿意为守一个方向放弃转头”，练习 3 验证“绕路带来的攻击角度是否值得付出代价”。相同阵容的可解释变化是本阶段目标。

## 6. 当前验证结果

2026-09-24，统一检查通过。三国项目共 412 项检查，包含 60 / 120 Hz 的方向防护和真实输入；基础项目回归也通过。掩体练习从初始状态出发，用相同兵力比较以下固定命令，未修改生命或瞬移单位：

| 命令计划 | 60 Hz 模拟战斗时间 | 结果 |
| --- | --- | --- |
| 两队集火敌盾兵，再打敌弓兵 | 34.40 秒 | 胜，我军剩弓兵 4 人 |
| 盾兵牵制，弓兵绕上端先打敌弓兵 | 25.00 秒 | 胜，我军剩弓兵 7 人 |
| 盾兵牵制，弓兵绕下端先打敌弓兵 | 30.73 秒 | 胜，我军剩弓兵 7 人 |
| 两队集火敌弓兵，再打敌盾兵 | 33.13 秒 | 胜，我军剩盾兵 1 人、弓兵 4 人 |
| 两队各打同类敌队，再打另一队 | 31.65 秒 | 败，敌军剩盾兵 4 人、弓兵 1 人 |

前两组还通过真实渲染器完整运行核对，胜负和存活人数一致。可使用 README 中的预览命令重现；这里只证明当前地图中路线与目标顺序能改变损失，不把单组结果视为平衡结论。上下绕方案均有盾兵阵亡，绕侧并不等于无损获胜。

当前驻守敌军不会主动出阵追远，因此消灭敌弓兵后，可以用射程优势收尾敌盾兵。这是本轮固定阵地练习的局限；反包抄、援护与撤退 AI 尚未验证。后续应在士气和撤退规则加入后再次比较，而不是把敌军原地承受射击当作完整战术 AI 已经成立。

## 7. 验收与下一步

| 验收项 | 可复现结果 |
| --- | --- |
| 正面与侧背 | 相同攻击条件下，正面盾牌生效，侧背失效；不存在全向盾牌残留 |
| 保护带与来袭方向 | 在带内且隔墙正面受箭才有掩体保护；离带、绕端与背袭不误判 |
| 叠加与兵种 | 掩体和盾牌取更强一项；近战不套远程减伤；弓兵贴身受压仍生效 |
| 转向与命令 | 攻击等待转向；Q 不自动追转侧后目标，X 可转向；移动/攻击能解除锁定 |
| 暂停与重开 | 暂停下令不提前旋转或结算；恢复正常；R 清除上一局状态 |
| 基础回归 | F1 保留 M1 全向盾牌与追击行为；M0 训练、选队和命令队列仍可用 |
| 玩法反馈 | 能指出绕路时间、牵制伤亡与攻击角度如何影响这一局，而不仅是看到新图标 |

当前优先确认保护范围是否好理解、转向是否过慢或过快、Q 是否值得使用、绕侧是否产生可解释的收益。通过实现检查后还要用户试玩，结果不满意就调整这一组规则。M2-02 的士气、侧击引发动摇与主动撤退，以及后续补给、视野、枪骑兵和 3 对 5 关卡，均未在本轮加入。
