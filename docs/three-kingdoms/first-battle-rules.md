# M1：第一场遭遇战玩法规格

本阶段先验证 **两支部队是否能打出清楚、可控、有取舍的战斗**。使用灰盒地图和占位角色，不推进正式美术。以下规则已实现并通过自动检查与实际渲染，等待用户试玩；数值是起始假设，不是已经验证的平衡结论。

## 1. 这一场玩什么

双方各有一队盾步兵和一队弓兵，每队 7 人，共 28 人。玩家指挥两队，敌军自动警戒和接战。地图有阻挡通行与攻击的墙体，双方兵力对等，不设随机增援。

**观察敌方部署 → 移动接近 → 盾兵牵制、弓兵选择目标 → 根据伤亡换目标或调整位置 → 全歼对方并查看伤亡 → 重开比较另一种打法。**

敌方全部小队被消灭即胜利；我方全部被消灭即失败；同一轮伤害结算后双方均被消灭则为平局。结果只结算一次，结束后停止战斗，可以按 R 重开。结果应列出双方初始人数、幸存人数与阵亡人数，方便比较打法。

本轮胜利条件暂时只有歼灭，不要求占点，也没有战役奖励或永久损失。目标是先看懂“为什么赢、为什么损失了这些兵”。

## 2. 操作与命令约定

| 操作 | 输入与效果 |
| --- | --- |
| 选队 | 左键点击友方存活队员，选择整支小队；拖拽框选；Shift 加选或取消单队 |
| 移动 | 右键空地，替换当前命令与队列，绕过墙体前往目的地；行军途中不自动停下来攻击 |
| 指定攻击 | 右键敌军，替换当前命令与队列；接近目标，满足射程与视线后攻击 |
| 追加命令 | Shift + 右键追加移动或攻击，每队最多 16 条命令（含当前命令）；前一条完成后执行下一条 |
| 停止并守卫 | X 清空当前命令与队列、停止移动；有可攻击目标进入射程时自动交战，不自行追远 |
| 战术暂停 | Space 暂停或恢复。暂停时仍可选队、下令、排队与移动镜头，部队移动、伤害和攻击冷却全部冻结 |
| 重开 | R 重建遭遇战，清除旧伤亡、结果与命令 |
| 镜头与选择 | WASD / 中键平移，滚轮缩放，F 聚焦选队，Esc 清除选择 |
| 快捷选队 | 1 选盾步兵，2 选弓兵，Tab 全选存活队伍 |

没有命令的玩家小队在原地守卫，只攻击当前射程和视线内的敌人。**“移动”用于脱离或换位，“攻击”用于追击目标**，两者不混成一个隐含指令。指定目标被消灭后，该攻击命令完成，继续处理后续命令；没有后续命令则守卫。死亡小队不能再被选择或接收命令。

M1 不提供主动撤退技能；右键安全位置只是普通移动，仍可能被敌人追击。受阻的箭矢和近战都不能穿墙，不能靠射程数值隔墙输出。

## 3. 两个兵种，各一个职责与限制

所有距离均为原型世界单位，使用小队中心计算射程；目前不逐一模拟每名士兵的武器碰撞。伤害按攻击时的存活人数计算，采用确定数值，暂不加入命中率、暴击和随机伤害。

| 参数 | 盾步兵 | 弓兵 |
| --- | --- | --- |
| 满编人数 | 7 | 7 |
| 每人生命 / 小队总生命 | 36 / 252 | 24 / 168 |
| 每人每次伤害 | 3 | 4 |
| 满编每次基础伤害 | 21 | 28 |
| 攻击间隔 | 1 秒 | 1.4 秒 |
| 攻击距离 | 58 | 220 |
| 移动速度 | 88 | 105 |
| 核心优势 | 承受远程伤害时只受到 65% 伤害 | 可从后排攻击并先手消耗 |
| 核心限制 | 移动慢、必须近身接敌 | 距离 70 以内存在视线可达的敌军时，输出降至 35%；生命较少 |

盾步兵在 M1 的远程减伤是**全方向**的兵种属性。转向、盾牌朝向和背击不产生额外伤害，也没有高地或掩体加成。这是临时简化；有方向的防护交给 M2 单独验证。

弓兵被任意敌队贴近后仍能攻击，但输出下降，给“让盾兵先接敌、保持弓兵距离”一个可观察的理由。隔墙敌人不触发贴身惩罚。没有弹药与装填资源，先观察接战距离和换位的取舍，避免第一场教学承载过多规则。

部队上方显示兵种、存活人数和血条；选中面板显示生命、当前命令和追加命令数。弓兵满足贴身惩罚条件时显示“贴身受压”。目前小队之间没有实体阻挡，盾兵通过抢先接敌吸引敌方目标，不能组成不可穿越的人墙。

## 4. 伤亡如何影响战斗

小队共享生命池，用剩余生命折算存活人数：剩余生命除以每人生命后向上取整，生命归零则无人存活。累计损失达到一名士兵的生命后减少一人，阵亡角色从阵型中移除，后续攻击输出相应降低。

例如满编盾队每次基础伤害为 21，剩余 4 人时为 12。因此集中攻击一队的收益是尽早削减敌方输出；分散伤害则可能同时面对两支仍能作战的队伍。是否因此能减少本方总伤亡，需要在同一初始状态下重开比较。

领队暂时作为最后一名阵亡的普通成员，**没有独立武将生命、士气光环、单挑、俘虏或死亡事件**。这是 M1 便于读懂人数与伤害的抽象，不能把它当作后续武将系统的定案。具名武将与战后生死、招募规则在 M3 接入。

## 5. 敌军能做什么

敌军在驻点警戒，发现 420 距离内且视线未被墙体阻挡的友方小队后接战。追击以初始驻点为基准，边界为 600；超出追击边界后返回驻点，避免无限追着玩家绕图。

盾队接近到近战距离，弓队在射程内攻击。敌军仍受相同生命、伤亡、射程和墙体阻挡规则约束。当前不做协同包抄、隐藏视野、战术撤退或主动占点，也不让敌人凭空补兵。

此边界有助于测试脱离接触，但也可能形成反复拉扯的占优打法。若试玩出现“最优玩法是一直后退射箭”，优先调整地图、攻击和移动的取舍；不直接把它包装成已经成立的战术深度。

## 6. 三个可重复的试玩练习

每个练习从 R 重开后的相同状态开始，记录结果与我方幸存人数，不以一次胜利作为平衡结论。

1. **前排与后排**：先把两队一起推上去打一遍；重开后让盾队先接敌，弓队保持射程。观察哪支队伍先减员、弓兵是否因贴近而失去输出、战报差多少人。
2. **集中火力与换位**：先让两队各打一个敌人；重开后集中攻击同一目标，再用移动命令把受威胁的弓队带离。观察减少一支敌队的时间，以及换位损失的攻击时间是否值得。
3. **暂停与路线**：接战前 Space 暂停，给盾队和弓队分别排出绕墙移动与攻击命令，再恢复。检查恢复后是否按预期执行；按 X 后是否立即取消旧计划并在原地守卫。

这些练习只验证兵种职责、目标选择、位置与命令可靠性。**M1 尚不能证明“以弱胜强”成立**；同阵容、同兵力的基础交战可理解后，M2 再引入掩体、侧翼、士气和撤退，比较弱势方不同打法的结果。

### 当前回归观察

从初始位置下令、此后不再微操的三组固定命令测试均正常结束：

| 双方兵力不变，仅改变玩家目标顺序 | 结果 | 获胜方存活 |
| --- | --- | --- |
| 两队集火敌盾兵，再打敌弓兵 | 玩家胜利 | 3 人 |
| 两队集火敌弓兵，再打敌盾兵 | 敌军胜利 | 5 人 |
| 盾兵先打敌盾兵、弓兵先打敌弓兵，再各打另一队 | 敌军胜利 | 3 人 |

这些结果来自当前地图、初始位置和数值的 60 Hz 确定性模拟，第一种打法另经真实渲染场景完整运行核对。它们证明目标与接敌路径能改变结果，不代表已经证明了普遍最优打法，也不是以弱胜强测试；后续平衡改动后应重新比较。

## 7. 本轮反馈如何影响下一步

试玩先回答四个具体问题：

- 从接敌到第一名士兵阵亡，有没有时间看清并作出反应？太快会调慢伤害节奏，太久会检查空等时间。
- 能否看出盾兵正在承伤、弓兵是否被贴身压制？读不清就补必要的状态反馈，不先增加画面细节。
- 两队指挥是否需要频繁暂停？暂停是否帮助组织计划，还是因为选队、目标和路径不可靠才被迫使用？
- 重开改变站位或集中目标后，结果有没有变化，能否说出原因？没有区别就先调基础交战与地图，不增加更多兵种。

验收顺序为：命令和暂停可靠 → 伤亡及战报可信 → 兵种职责能被体验到 → 交战节奏可调整。M2 尚未开始；收到意见后先修本轮问题，再加入有方向的掩体和面向。
